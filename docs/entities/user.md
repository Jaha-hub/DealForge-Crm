# User — Пользователь

**Таблица:** `users`  
**Статус:** Реализовано (Domain + Infrastructure + API)

---

## Описание

Сотрудник компании, имеющий доступ к платформе. Роль определяет, что пользователь видит и что может делать.

---

## Поля

| Поле | Тип БД | Ограничения | Описание |
|---|---|---|---|
| `id` | UUID | PK, default uuid4 | Уникальный идентификатор |
| `first_name` | VARCHAR(255) | NOT NULL | Имя |
| `last_name` | VARCHAR(255) | NOT NULL | Фамилия |
| `email` | VARCHAR(320) | NOT NULL, UNIQUE | Email (используется для входа) |
| `username` | VARCHAR(255) | NOT NULL, UNIQUE | Логин |
| `password_hash` | TEXT | NOT NULL | Хэш пароля (Argon2) |
| `role` | VARCHAR(30) | NOT NULL, CHECK | Роль пользователя |
| `is_active` | BOOLEAN | default=true | Активен ли аккаунт |
| `last_interaction` | TIMESTAMP WITH TZ | nullable | Время последнего действия |
| `created_at` | TIMESTAMP WITH TZ | NOT NULL | Дата создания |
| `updated_at` | TIMESTAMP WITH TZ | NOT NULL | Дата последнего изменения |

---

## Роли (`role`)

| Значение | Название | Что может |
|---|---|---|
| `admin` | Администратор | Полный доступ: пользователи, воронки, источники, кастомные поля, аналитика |
| `director` | Руководитель | Просмотр всего, аналитика, назначение менеджеров, управление воронками |
| `sales_manager` | Менеджер по продажам | Своя команда: лиды, аналитика по команде |
| `consultant` | Консультант | Только свои лиды (назначенные на него) |

---

## Бизнес-правила

- `email` и `username` уникальны в системе
- Пароль никогда не хранится в открытом виде — только Argon2-хэш
- `is_active = false` — пользователь не может войти в систему
- `consultant` видит лиды **только** назначенные на него (`assign_to = user.id`)
- `consultant` может создавать лиды в любой воронке (ограничение бизнес-логикой, не FK)
- Только `admin` может создавать и деактивировать пользователей

## Связи

| Связь | Тип | Описание |
|---|---|---|
| Lead.assign_to → User | One-to-Many | Пользователю назначены лиды |
| LeadHistory.user_id → User | One-to-Many | Пользователь вносил изменения |
| Notification.user_id → User | One-to-Many | Пользователь получает уведомления |

## API эндпоинты

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| `POST` | `/api/v1/users/` | admin | Создать пользователя |
| `GET` | `/api/v1/auth/me` | все | Профиль текущего пользователя |
| `PATCH` | `/api/v1/auth/me` | все | Обновить имя/фамилию |
| `POST` | `/api/v1/auth/change-password` | все | Сменить пароль |
| `POST` | `/api/v1/auth/login` | — | Авторизация |
| `POST` | `/api/v1/auth/refresh` | — | Обновить JWT-токен |
