# Use Cases — Варианты выбора (LeadCustomFieldEnum)

---

## UC-ENUM-01: Добавить вариант выбора

**Актор:** `admin`, `director`  
**API:** `POST /api/v1/custom-fields/{id}/enums`

### Предусловия
- Текущий пользователь — `admin` или `director`
- Поле с `id` существует, не удалено
- Тип поля — `select_one` или `select_many`
- `value` уникален в пределах данного поля

### Порядок действий

1. Пользователь отправляет `value` (текст варианта)
2. Система проверяет роль; если нет — `403`
3. Загружает `LeadCustomField` по `id`; если не найдено или удалено — `404`
4. Проверяет, что `field_type` = `select_one` или `select_many`; если нет — `400` («Это поле не поддерживает варианты»)
5. Проверяет уникальность `value` в пределах данного поля; если уже есть — `409`
6. Создаёт `LeadCustomFieldEnum` с `custom_field_id = id`, `value = value`
7. Возвращает созданный вариант (`201 Created`)

### Что решает
Наполняет выпадающий список (select) доступными вариантами. Без вариантов поле типа `select_one`/`select_many` невозможно использовать в карточке лида. Уникальность значений в пределах поля предотвращает дубли в дропдауне.

### Альтернативные сценарии
- **Нет прав:** `403`
- **Поле не найдено:** `404`
- **Поле не является select-типом:** `400`
- **`value` уже существует в этом поле:** `409`

### Постусловия
- `LeadCustomFieldEnum` создан и привязан к полю
- Вариант появляется в выпадающем списке при заполнении карточки лида

## UC-ENUM-02: Удалить вариант выбора

**Актор:** `admin`, `director`  
**API:** `DELETE /api/v1/custom-fields/{id}/enums/{enum_id}`

### Предусловия
- Текущий пользователь — `admin` или `director`
- Вариант с `enum_id` существует и принадлежит полю `id`
- Вариант **не используется** ни в одном `LeadCustomFieldValue`

### Порядок действий

1. Система проверяет роль; если нет — `403`
2. Загружает `LeadCustomFieldEnum` по `enum_id` и `custom_field_id = id`; если не найден — `404`
3. Проверяет, нет ли `LeadCustomFieldValue`, ссылающихся на этот `enum_id` (через `enum_value` или `enum_values`)
4. Если есть — `409 Conflict` («Вариант используется в N лидах, удалите значения перед удалением варианта»)
5. Физически удаляет `LeadCustomFieldEnum`
6. Возвращает `204 No Content`

### Что решает
Позволяет убрать устаревший или ошибочный вариант из выпадающего списка. Защита от удаления используемого варианта предотвращает потерю данных: если вариант выбран в каких-то лидах, его нельзя удалить до очистки значений в карточках.

### Альтернативные сценарии
- **Нет прав:** `403`
- **Вариант не найден:** `404`
- **Вариант используется в лидах:** `409`

### Постусловия
- `LeadCustomFieldEnum` физически удалён из БД
- Вариант исчезает из выпадающего списка в карточках лидов
